# SESI SPACE

Experiência educacional interativa sobre o Sistema Solar.

## Recursos
- Fases da Lua com ciclo de aproximadamente 29,5 dias
- Terra realista no laboratório lunar
- Sistema Solar 3D
- Viagem de câmera entre planetas
- Cinturão de asteroides
- Lua da Terra e luas galileanas de Júpiter
- Comparador de planetas e cálculo de peso

## Executar localmente
Abra `index.html` no Chrome ou Edge.

## Publicar com GitHub Pages
1. Envie todos os arquivos deste projeto para a raiz do repositório.
2. No GitHub, abra **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**.

O site ficará disponível no endereço de GitHub Pages exibido nessa tela.
